# Data

This project uses the **Advertising** dataset from *An Introduction to Statistical Learning (ISL)*.

The dataset contains 200 observations with advertising expenditure across three channels:

- `TV`
- `Radio`
- `Newspaper`

and the corresponding target variable:

- `Sales`

The original dataset is available from the official *An Introduction to Statistical Learning* resources page:

https://www.statlearning.com/resources-python

To reproduce the analysis, download `Advertising.csv` from the official ISL resources and place it in this directory.

Expected structure:

    data/
    ├── Advertising.csv
    └── README.md

The dataset itself is not redistributed in this repository.
